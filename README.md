## 🚀 Featured Projects

### 🕹️ Game Development & Interactive Simulations
* **3D Open World Prototype (Unity):** A GTA-inspired third-person action prototype demonstrating terrain sculpting, dynamic lighting, third-person locomotion, and modular C# gameplay systems.
* **3D Hack & Slash Web Game (Unity):** A WebGL-deployed action game featuring responsive combat mechanics, Cinemachine, Animation BlendTrees, and NavMesh enemy AI.
* **Chronobot: 2D Metroidvania Platformer (Godot 4):** A complete 2D shooting platformer built with GDScript, state-machines, custom shaders, TileMaps, and resource-based save systems.
* **Solar System 3D Simulation (Unity & API):** An interactive astronomical simulation fetching real-time planetary telemetry from an external REST API.
* **Cinematic Game Intro Cutscene (Unity):** Story-driven 3D cutscene utilizing Unity Timeline, multi-camera Cinemachine switching, atmospheric lighting, and synchronized subtitles.
* **FPS Maze Game (Unity):** First-person shooter built around spatial maze level design and tight environment collision mechanics.

### 🤖 Automation & Robotics
* **Real-Time Game Automation Bot (Python & OpenCV):** Autonomous computer-vision bot that captures live screen feeds, detects obstacles using ROI optimization, and executes low-latency keypresses.
* **Smart Floor Cleaner Robot (Arduino, SolidWorks & V-REP):** Android-controlled floor cleaning robot designed in SolidWorks and simulated in V-REP/CoppeliaSim.

### 🎨 3D Art & Mechanical CAD Design
* **Blender 3D Design:** Character modeling, environmental scenes (volumetric fog, lighting), and low-poly/stylized assets.
* **CAD Engineering Gallery (SolidWorks, Fusion 360 & SketchUp):** Mechanical assemblies, 2D engineering drawings, pipe routing, PLC-automated bottle filling systems, gearboxes, and robotics chassis.
